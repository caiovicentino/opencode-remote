# RT-439 — Injeção shell/AppleScript em `POST /__ocr/handoff`

## Problem
`apps/daemon/src/index.ts:1466-1494` (handler `/__ocr/handoff`) monta:

```
do script "cd ${dir.replace(/"/g, '\\"')} && opencode -s ${sessionId}"
```

- O escape só de `"` protege a camada do literal AppleScript, mas NÃO a camada shell:
  `do script` executa o texto no shell do usuário, então `;`, `$()`, backticks, `&&`, `|`,
  `\` final ou newline em `dir` executam comandos arbitrários (mesma classe que P2-048
  corrigiu no takeover — ver comentário em `apps/daemon/src/pilotforensic.ts:417-428`).
- `dir` vem de `GET /session/<id>` do opencode (`info.directory || info.path`) — é o cwd do
  projeto, controlável por quem cria a sessão/diretório (ex.: repo clonado com nome hostil).
- `sessionId` só é checado com `startsWith("ses")`: é interpolado cru no comando shell
  (`opencode -s ses;rm -rf ~`) E no path da URL do opencode (`ses/../..` → path traversal na
  API local). Outras rotas já usam `/^ses_[A-Za-z0-9]{4,64}$/` (index.ts:1042).

## Approach
1. Novo módulo puro `apps/daemon/src/handoff.ts` (sem I/O, sem imports de fs/child_process):
   - `validateHandoffSessionId(s: unknown): string | null` — aceita só
     `/^ses_[A-Za-z0-9]{4,64}$/`.
   - `validateHandoffDirectory(d: unknown): string | null` — string, absoluta (`startsWith("/")`),
     comprimento 1..4096, sem caracteres de controle (`/[\x00-\x1f\x7f]/` → null). NÃO usar
     allowlist estreita tipo takeover (diretórios de projeto reais têm espaços, acentos, `'`,
     parênteses); a segurança vem da citação abaixo. Retorna `d` inalterado se ok.
   - `shellQuote(s: string): string` — citação POSIX por aspas simples:
     `"'" + s.replace(/'/g, "'\\''") + "'"`.
   - `buildHandoffCommand(dir, sessionId): string` →
     `cd ${shellQuote(dir)} && opencode -s ${shellQuote(sessionId)}`.
   - `buildHandoffOsascriptArgs(command: string): string[]` → argv para `execFile("osascript", …)`:
     `["-e","on run argv","-e",'tell application "Terminal"',"-e","activate","-e",
       "do script (item 1 of argv)","-e","end tell","-e","end run", command]`.
     O valor NUNCA é interpolado no fonte AppleScript — chega como argv, então a camada
     AppleScript fica inerte por construção; a camada shell fica inerte pelo `shellQuote`.
2. Handler em `index.ts`:
   - Validar `sessionId` com `validateHandoffSessionId` ANTES do `fetch`; inválido → 400
     `{ error: "valid session id required" }` (mesma frase de `/__ocr/context`).
   - Usar o id validado na URL `/session/${id}`.
   - Após o fetch, `validateHandoffDirectory(dir)`; null → 422
     `{ error: "session directory rejected" }` + `log("warn", …)` com `sessionId` apenas
     (nunca logar o valor hostil inteiro; se logar, truncar a 200 chars via JSON).
   - Substituir o template string por
     `execFile("osascript", buildHandoffOsascriptArgs(buildHandoffCommand(dir, id)))`.
   - Resto (audit `session.handoff`, resposta `{ ok, dir }`, erros 404/502/500) inalterado.
3. Não tocar no takeover (`/api/pilot-takeover`, index.ts:4734+) — já endurecido por P2-048.

## Edge cases
- Diretório com espaço, acento, `'`, `"`, `$`, `` ` ``, `;`, `&`, `|`, `(`, `)`, `\`, `*`, `~`
  → aceito e citado; o shell recebe o caminho literal (sem expansão de `~`/glob).
- Diretório com `\n`, `\r`, `\t`, NUL, `\x7f` → 422 (newline via `do script` vira Enter
  digitado no Terminal).
- Diretório relativo, vazio, não-string (número/objeto no JSON do opencode) → 422 / 404
  (vazio segue o 404 atual "session directory unknown").
- `sessionId` ausente, não-string, `ses`, `ses_`, `ses_abc` (<4), `ses_../x`, `ses_a;b`,
  `ses_` + 65 chars → 400 sem nenhum `fetch` nem `osascript`.
- `info.directory` hostil mas `info.path` limpo: manter a precedência atual
  (`directory || path`) e validar o valor escolhido — não cair silenciosamente pro outro.
- Plataforma não-macOS: comportamento atual (osascript falha → 500) inalterado.

## Acceptance criteria
- `npm run typecheck` verde.
- `npm run test:unit` verde, incluindo `scripts/handoff.test.ts` com checks de:
  - `validateHandoffSessionId`: aceita `ses_AbC123xyz`; rejeita todos os ids do Edge cases.
  - `validateHandoffDirectory`: aceita `/Users/a/My Proj (1)/it's`; rejeita relativo,
    `""`, `"/a\nb"`, `"/a\u0000b"`, 4097 chars, não-string.
  - Round-trip REAL de shell: para ≥8 payloads hostis (`foo"; touch CANARY; echo "`,
    `$(touch CANARY)`, `` `touch CANARY` ``, `a'b; touch CANARY; '`, `x\`, `a && touch CANARY`,
    `a | touch CANARY`, `*`), `execFileSync("/bin/sh", ["-c", "printf %s " + shellQuote(p)])`
    devolve exatamente `p` e o arquivo CANARY (em `mkdtemp`) NÃO existe depois.
  - `buildHandoffCommand("/tmp/x'y", "ses_abcd")` === `cd '/tmp/x'\''y' && opencode -s 'ses_abcd'`.
  - `buildHandoffOsascriptArgs(cmd)`: último elemento === `cmd`; nenhum elemento `-e`-statement
    contém `cmd` nem o diretório (o valor só aparece como argv).
  - Pin estrutural (lição P3-447): regex sobre `apps/daemon/src/index.ts` prova que o bloco
    `/__ocr/handoff` não contém mais `do script "cd ${` nem `.replace(/"/g` e chama
    `buildHandoffOsascriptArgs`.
- `npx tsx scripts/invariants.ts` verde (não é editado).
- Manual (macOS, opcional): handoff de sessão cujo cwd é `/tmp/a b'c` abre Terminal em
  `/tmp/a b'c` rodando `opencode -s <id>`.
